# Marketing website UI kit
Parent-facing landing page. Click-through: EN ⇄ العربية toggle (flips to RTL + Arabic fonts), library tabs, mobile menu (<900px), CTAs link to the app kit (create / checkout).

Files: `i18n.jsx` (all copy, EN + AR), `Nav.jsx`, `Hero.jsx`, `Sections.jsx` (HowItWorks, Library, Features, Pricing, Testimonial), `Footer.jsx`, `site-main.jsx`.

Illustration areas are `BlobFrame` placeholders — drop real character art in via `src`.
