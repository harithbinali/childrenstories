# Parent app UI kit
Logged-in parent experience. Hash routes: `#home` dashboard · `#create` story creator wizard (4 steps → generating → ready dialog) · `#read` bedtime reader (read-aloud word highlight, page turns) · `#checkout` plan upgrade (monthly/yearly, card form, success dialog + toast).

Sidebar on ≥900px, floating bottom tab bar on mobile. Language toggle in sidebar flips RTL (chrome only — screen copy is English).

Files: `Shell.jsx`, `Dashboard.jsx`, `Creator.jsx`, `Reader.jsx`, `Checkout.jsx`, `parent-main.jsx`.
