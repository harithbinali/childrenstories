Base surface for grouped content — feature tiles, plan cards, dashboard panels.
```jsx
<Card tone="sun" wobble interactive tilt={-1.5}><h3>Bedtime tales</h3></Card>
<Card variant="sticker" tone="sky">…</Card>
```
- Rotate pastel tints in order sun → sky → bubble → mint → grape → tangerine across a row.
- `outlined` for the one card you want to look "printed" (e.g. featured plan).
